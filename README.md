# Від Карпат до Сеула

Сайт-візитка для збору коштів на поїздку молоді Ужгорода на Всесвітній день молоді в Сеулі (3–8 серпня 2027).

Статичний сайт на [Astro](https://astro.build), публікується на GitHub Pages. Пожертви приймаються лише готівкою під час особистої зустрічі, тому на сайті немає форм, платіжних даних, аналітики й трекерів.

## Як запустити локально

Потрібен Node.js 22 або новіший.

```bash
npm install
npm run dev
```

Сайт відкриється за адресою, яку покаже команда (http://localhost:4321/назва-репозиторію/). Зміни у файлах видно одразу. Зупинити сервер: `npx astro dev stop`.

| Команда | Що робить |
|---|---|
| `npm run dev` | локальний сервер для роботи |
| `npm run build` | збирає готовий сайт у теку `dist/` |
| `npm run preview` | показує зібраний сайт локально |
| `npm run check` | перевіряє код на помилки |
| `npm run og` | перемальовує картинку для соцмереж |
| `npm test` | перевірки Playwright (потрібен запущений `npm run preview`) |
| `npm run lighthouse` | Lighthouse у мобільному режимі (потрібен запущений `npm run preview`) |
| `npm run shots` | скріншоти сторінок у теку `screenshots/` |

## Як змінити тексти

Усі тексти лежать в одному файлі: [src/content/texts.ts](src/content/texts.ts). Правте лише те, що в лапках.

- **Назва проєкту** — `site.name` на початку файлу. Вона підставляється в шапку, підвал, заголовки й метатеги. Слова, виділені кольором на першому екрані, — у `site.nameAccents`.
- Після зміни назви запустіть `npm run og`, щоб оновити картинку для соцмереж.
- Дата, до якої рахує таймер, — `site.eventStart`.

## Як змінити контакти

Файл [src/data/contacts.ts](src/data/contacts.ts). Для кожної особи вкажіть:

- `name`, `role` — ПІБ і роль;
- `phone` — номер у форматі `+380501234567`, без пробілів;
- `telegram` — ім'я користувача без `@`;
- `whatsapp`, `viber` — `true`, якщо на цьому номері є месенджер;
- `email` — адреса пошти.

Посилання для дзвінка й месенджерів складаються самі. Якщо якогось каналу немає, видаліть його рядок — кнопка зникне. Щоб прибрати третю особу, видаліть її блок цілком.

## Як замінити фото

Покладіть файл у теку [src/assets/photos/](src/assets/photos/) з потрібною назвою. Розширення може бути `.jpg`, `.jpeg`, `.png` або `.webp`. Сайт сам зробить зменшені копії у форматі WebP.

| Назва файлу | Де показується | Яке фото |
|---|---|---|
| `hero` | перший екран головної, галерея | групове фото всієї молоді (уже є) |
| `community` | «Хто ми» на головній і на сторінці, галерея | живе фото спільноти: зустріч, спів, прогулянка |
| `gallery-1` | галерея | молитва або зустріч спільноти |
| `gallery-2` | галерея | спільна мандрівка чи похід |
| `gallery-3` | галерея | ярмарок або власноруч зроблені речі |
| `gallery-4` | галерея | концерт або репетиція |

Поки файлу немає, на його місці стоїть заглушка з підказкою.

- Найкраще підходять горизонтальні фото завширшки від 2000 px. Надто великі файли (понад 3–4 МБ) краще зменшити перед додаванням.
- Підписи для незрячих користувачів (`alt`) — у [src/data/photos.ts](src/data/photos.ts). Оновіть їх, коли додасте фото.
- Щоб змінити набір фото в галереї, поправте список `ids` у [src/pages/about.astro](src/pages/about.astro).
- Після заміни `hero` запустіть `npm run og`.

## Як додати макет візитівки

Покладіть файл `card.png` (або `.jpg`, `.webp`) у теку [src/assets/card/](src/assets/card/). Він з'явиться замість заглушки на головній і на сторінці «Як допомогти». Пропорції візитівки: 85 × 55 мм, тобто приблизно 1700 × 1100 px.

## Як змінити стиль

Кольори, шрифти, відступи й радіуси зібрано в одному файлі: [src/styles/tokens.css](src/styles/tokens.css). Щоб підлаштувати сайт під макет візитівки, достатньо поправити кольори там.

## Публікація

Сайт публікується сам: після кожного `git push` у гілку `main` GitHub Actions збирає його й викладає на GitHub Pages (файл [.github/workflows/deploy.yml](.github/workflows/deploy.yml)).

Адреса сайту задається в [astro.config.mjs](astro.config.mjs) двома рядками: `GITHUB_USER` і `REPO_NAME`. Якщо перейменуєте репозиторій, змініть `REPO_NAME`.

## Структура

```
src/
  content/texts.ts     усі тексти
  data/contacts.ts     контакти
  data/photos.ts       список фото й підписи до них
  assets/photos/       фото
  assets/card/         макет візитівки
  styles/tokens.css    кольори, шрифти, відступи
  components/          шапка, підвал, таймер, картки, галерея
  layouts/Base.astro   спільний каркас сторінки
  pages/               сторінки: головна, about, trip, help, 404
scripts/               перевірки, скріншоти, картинка для соцмереж
```
